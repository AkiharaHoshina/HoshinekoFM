## 二、关键技术信息（坑点速查）

### 排查实录
- **「功能完全无效」但 e2e 全绿**：运行中的打包版 portal 服务持单实例锁——仓库里任何启动都转发到旧进程加载旧代码；诊断手段：`--user-data-dir` 绕过锁 + CDP `Input.dispatchKeyEvent`（真实输入管线）驱动真实应用验证
- **本机磁盘快**（仓库根 7GB du 仅 40ms）：无法用真实 du 确定性测超时/杀死路径——harness 用 `HOSHINEKO_DU_STALL_MS` 在 du 前 sleep、`HOSHINEKO_DU_TIMEOUT_MS` 覆盖超时阈值（fs.ts 与 harness 同一条实现，无需手工副本）
- **pdf.js 并发 render 不安全**：canvas.width 赋值清空画布并复位 context 变换，旧任务继续绘制 → 黑底/上下翻转；cancel 后新任务重置画布完整重绘
- **预览缓存**：`preview://` 同 URL 命中浏览器缓存——外部保存后必须带 `?v=mtime` 缓存戳 + 元素 key 强制重建
- **Markdown 本地图**：DOMPurify 默认不允许 `preview://` 等自定义 scheme——先消毒后改写（写回经 DOM API 自动转义）；`#`/`?` 编码防 URL 截断

### Electron / React
- `sendInputEvent` keyCode 用 `'ArrowDown'` 得到空 `e.key`——必须用 `'Down'/'Up'/'Left'/'Right'`
- 设置行数随开关增减会移动硬编码下标——e2e 定位设置行改按文案匹配（16/16b 教训）
