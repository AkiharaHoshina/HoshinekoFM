## 1. 文件设置预览吸顶空隙

- **根因**：顶栏 `marginBottom: 16px` 与滚动容器 padding-top 8px 之间形成裸条，
  预览 sticky `top: 0` 吸在滚动容器上沿，下层行从 16px 条带透出。
- **修改**：ExplorerTab 顶栏容器内联样式 `marginBottom` 改条件值——设置页
  （`isSettingsPath(currentPath)`）为 `0`，其余保持 `16px`。预览吸顶即贴
  地址栏下沿（预览自身 padding-top 4px 作呼吸）；非滚动时由
  `.settings-page-scroll` padding-top 8px 保持间距。
- **e2e**：69 增加几何断言——滚动到预览吸顶后，预览 top 与顶栏 bottom
  间隙 ≤ 1px。

## 2. 「进入」→「自定义」

- `settings.open_rule_manager_enter` × 12 语言值改为与
  `settings.search_limit_edit`（「自定义」/Customize/…）完全一致的文案。
  无组件改动。

## 3. 图标大小滑条松手生效

- `FilesSettings` 内图标大小行改为与界面缩放同款：本地
  `const [dragIconSize, setDragIconSize] = useState<number | null>(null)`；
  `onInput` 只写 drag（数值标签实时）、`onChange`（md-slider 提交）才
  `s.setIconSize(v)` 并清 drag。显示值 = `dragIconSize ?? s.iconSize`。

## 6/7. 搜索上限/超时页内输入框（空/无效 = 无限制）

- **新 util `src/utils/searchLimit.ts`**：
  ```ts
  export const SEARCH_LIMIT_MAX = 100000;
  /** 原始输入 → 生效上限：正整数 → min(n, 100000)；空/非数字 → null（无限制） */
  export function parseSearchLimitStr(raw: string | null | undefined): number | null;
  ```
- **App**：`searchLimit`/`searchTimeout` 类型改 `string`（默认 `'200'`/`'30'`）；
  `handleRestoreDefaults` 重置为 `'200'`/`'30'`。
- **ExplorerTab**：`effectiveSearchLimit`/`effectiveSearchTimeout` 改经
  `parseSearchLimitStr` 解析（session 级「调整上限」覆盖逻辑不动）。
- **SearchSettings**：删「自定义」按钮 + `SearchLimitDialog`/
  `SearchTimeoutDialog`，改 `OutlinedTextField`（value = 原始串，
  `onInput` 即 `setSearchLimit(v)`）——**输入即生效、原文保存**。
- **删除** `SearchLimitDialog.tsx`/`SearchTimeoutDialog.tsx`（及其 CSS 若有）
  ——搜索页内「调整上限」是 SearchFilterBar 自己的内联 draft，不受影响
  （已确认非同一组件）。
- **提示**：两行 sub 追加新键 `settings.search_invalid_hint` × 12
  （「如果输入为空或输入无效字符，则视为无限制」），独立小字行。
- **e2e 74 改写**：输入 `2` → localStorage `'"2"'` + 搜索 2 条 capped；
  输入 `妈妈我要生了` → 原样保存 + 搜索不截断；清空 → `'""'` 无限制。

## 9. 快捷方式「创建/移除」按钮

- **后端**：`launcherEntry.ts` 加 `getLauncherEntryExists(kind)`（.desktop

  （preload/d.ts 同步；harness 经共享模块自动同源）。
- **App**：删 `autoCreateDesktopEntry`/`autoCreateAppMenuEntry` 两个键 +

- **i18n**：`settings.create_entry`/`settings.remove_entry` × 12（创建/移除）。
- **e2e**：56 改写为按钮模型（沙箱 env 保持）；44 预期对象删两个

## 10. 语言下拉宽度 = 展开菜单宽度

- md-select 弹层宽跟随最长选项；收起态字段定宽 160px 是问题所在。
  **实现**：`I18nSettings` 用隐藏 measurer span（`position: absolute;
  visibility: hidden`）渲染全部语言名，`useLayoutEffect` 取最大宽度 +
  下拉箭头/内边距余量（~48px），设到 host `style.width`（`max-width` 上限
  如 320px 防超宽）。删 `.settings-select` 对该行的 160px 定宽（用行内
  宽度）。
