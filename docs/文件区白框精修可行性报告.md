# 文件区白框与快捷添加对话框精修可行性报告（review 24）

> **状态：决策点已全部定案并实施**（2026-10-01）。
> **决策点定案**：① 多选进站白框落游标行；② 选择器/保存器窗口的文件区同款同步；③ 任何鼠标点击（含点击当前选中项本身）白框都消失。范围：主窗口文件区 Tab 进站白框语义（review 20 对象行同款推广到文件区）、快捷添加对话框复刻文件区选择逻辑（Shift+Esc 清选、滚动跟随键盘焦点）。纯渲染层改动，无后端/IPC 变更。
> 调研基准：v0.11.49-dev（review 23 `52c0013` 之后）。

## 1. 需求解读（两项）

1. **文件区 Tab 进站白框**：Tab 切换到文件区并选中文件（文件夹）项时，给所选**单项**加白框；以任何手段换选（键盘方向键、鼠标点击其他项目、发起框选、点击背景）则白框消失。
2. **快捷添加对话框选择容器复刻文件区组件与逻辑**：Tab 切换到容器时选择第一项（若无选择）、有选择则保持（已实现）；Shift+方向键多选保留（已实现）；**新增 Shift+Esc 取消所有选择**；**新增上下位置（右侧滚动条）跟随键盘焦点**。

## 2. 现状盘点（file:line 证据）

### 2.1 文件区（问题 1）

- 文件行已有焦点环样式：`.file-list-item:focus-visible { outline: 2px solid var(--md-sys-color-primary); background-color: surface-container-highest }`（FileList.css:60-63）——白框基础已就绪；`.selected` 样式排其后（:65），背景覆盖为 secondary-container、2px 环保留。
- 行 tabIndex 恒 -1（Row.tsx:370/452）——行可程序聚焦但从不受焦。
- 进站 `filesZoneFocusRef`（ExplorerTab.tsx:1370）：无选中选视口第一个可见 → **焦点落容器**（不聚焦条目——review 19 P1 语义）。
- 换选手段：
  - 方向键：窗口级 keydown 箭头分支（~1975）——移动选择后无焦点处理；
  - 鼠标点击他项：行 click → 选择改变（点击 tabindex 元素天然聚焦被点行——鼠标点击不触发 :focus-visible，白框不出现）；
  - 发起框选/点击背景：FileList 容器 onMouseDown → handleBackgroundMouseDown（FileList.tsx:591-599）——无焦点处理。
- 选择器/保存器窗口的文件区是独立实现（FilePicker.tsx）。

### 2.2 快捷添加对话框（问题 2）

- review 23 已实现：Tab 进列表站选首个/保持、焦点落选中项白框、↑/↓ 单选、Shift+↑/↓ 范围多选、焦点回容器白框消失（QuickAddDialog，SearchFilterBar.tsx:578-730）。
- 缺：Shift+Esc 清选（普通 Esc 留给 md-dialog 关闭语义）；↑/↓ 移动时列表不滚动跟随（`.search-quickadd-list` overflow-y:auto，超出部分移动焦点后不可见）。

## 3. 设计

### 3.1 文件区进站白框（问题 1）

- 行 roving tabIndex：选中行 0、其余 -1（Row.tsx 列表/网格两处，与 review 20 对象行同款）。
- `filesZoneFocusRef` 进站改**聚焦选中行**：无选中 → 选视口第一个可见 → 按 data-path 直接聚焦该行（类名要等下一轮渲染）；有选中 → 聚焦游标行（cursorPath ?? lastSelectedPath ?? 首个选中）；行未挂载（虚拟化滚出视口）回落容器（白框无从显示）。
- **任何换选手段白框消失**（焦点回容器）：
  - 方向键/Home/End/PgUp/PgDn/Enter 导航分支：处理末尾 `fileZoneRef.current?.focus()`；
  - Escape 清选分支：同上；
  - 背景 mousedown（发起框选/点击背景取消选择）：窗口级 mousedown 监听扩展——目标在文件区内且不在条目/预览面板/分隔条上时聚焦容器；
  - 点击他项：点击天然聚焦被点行（鼠标不触发 :focus-visible）——旧行失焦白框消失、新行无框 ✓ 零代码。
- 兼容性核查：窗口级 keydown 以「目标在 files 区内」判定（行在区内 ✓ 方向键/Enter/Space/type-ahead 全部不受影响）；App 全局 Tab 拦截 preventDefault → 行不进原生 Tab 序（review 19 崩溃点不回归）。

### 3.2 快捷添加对话框（问题 2）

- **Shift+Esc 取消所有选择**：窗口级捕获监听（与 Tab 拦截同款）拦截 `Escape + shiftKey` → preventDefault + stopPropagation（不触发 md-dialog 关闭）→ 清空 selected/游标/锚点——对话框内任意焦点位置生效（搜索框内亦可）。
- **滚动跟随键盘焦点**：↑/↓ 移动后 `scrollIntoView({ block: 'nearest' })` 聚焦项（`.search-quickadd-list` overflow-y:auto 内滚动）。

## 5. 决策点（已全部定案）

1. **多选进站白框落点**——**定案**：游标行（cursorPath ?? lastSelectedPath ?? 首个选中）。
2. **选择器/保存器文件区**——**定案**：同款进站白框语义（FilePicker filesZoneFocusRef 同步改造：无选中选视口第一个可见**可选项**、焦点落选中行）。
3. **点击当前选中项本身**——**定案**：任何鼠标点击白框都消失（窗口级 click 监听把焦点抢回容器）。

## 6. 实施记录

- **主窗口文件区（问题 1）**：行 roving tabIndex（选中行 0/其余 -1，Row.tsx 列表/网格两处）；`filesZoneFocusRef` 进站聚焦选中行（无选中选视口第一个可见 → 按 data-path 聚焦；有选中聚焦游标行；行未挂载回落容器）；白框 = 既有 `.file-list-item:focus-visible` 焦点环。
- **任何换选手段白框消失**：方向键/Home/End/PgUp/PgDn/Space/Ctrl+A/Escape 分支末尾 `fileZoneRef.focus()`；背景 mousedown（框选/点击背景）窗口级监听聚焦容器；**条目点击经窗口级 click 监听抢回焦点**——浏览器默认焦点在监听之后落到被点行且 `:focus-visible` 的「前一元素匹配即继承」启发式会让白框跟随到被点行（实测踩中），不可在 mousedown 里抢（早于默认焦点失效）、不可 preventDefault（打断原生拖拽）。
- **选择器同步（决策 2）**：FilePicker 同款 filesZoneFocusRef（含 isSelectable 过滤）+ 方向键/Home/End/Space 回容器 + mousedown/click 监听。
- **快捷添加对话框（问题 2）**：窗口级捕获 Shift+Esc → 清空 selected/游标/锚点（普通 Esc 留给 md-dialog 关闭）；↑/↓ 移动后 `scrollIntoView({ block: 'nearest' })` 滚动跟随键盘焦点。
- **e2e**：25 改断言（进站焦点落选中行 + 白框 + 方向键回容器）；26 改写（进站即选中首项、Shift 范围锚点语义随新进站变化）；新增 101（主窗口进站白框 + 点击他项/背景/框选白框消失 + 选择器同款 + 对话框 Shift+Esc/滚动跟随）。
- 回归：15/20/21/25/26/29/42/44/52/53/55/57/59/63/74/76/78/82/84/87/88/90/93/95/96/97/98/99/100/101 全绿；build/lint 全过。

## 7. 风险与可行性结论（回顾）

- **全部可行**，纯渲染层。主要风险（均已处理）：进站聚焦行是 review 19「不聚焦条目」的反转（窗口级 keydown 以 zone 判定 ✓ 无回归）；虚拟化选中行未挂载回落容器（已知取舍）；条目点击抢焦点与浏览器默认焦点/:focus-visible 继承启发式的交互（click 阶段抢、不 preventDefault 保拖拽）。
