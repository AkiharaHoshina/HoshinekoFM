# Hoshineko File Manager — 项目进度

> 本文档基于代码库现状（`main` 分支，版本 0.11.33）整理，记录本项目已实现与未实现的功能。
> 最后更新：2026-09-04

## 项目概况

Hoshineko File Manager（构建产物名 "HoshinekoFM"）是基于
[material-3-file-explorer](https://github.com/bhimio1/material-3-file-explorer) 重构的现代文件管理器：
Electron + React 19 + Material 3（`@material/web`），后端使用 Linux 系统命令与 D-Bus 服务，
目标平台为 Linux（AppImage 分发）。

## 一、已实现

### 1. 窗口与应用架构

- 多窗口单后端：所有窗口共享一个主进程，窗口实例集合管理
- 单实例锁：二次启动打开新窗口并聚焦（已修复 niri 工作区回跳问题）
- 启动路径按窗口解析（命令行参数传入文件/目录）
- 防白屏（`ready-to-show`）、Wayland 窗口装饰标志
- **frameless 自定义 M3 标题栏**：原生标题栏彻底隐藏（`frame: false` + 菜单置空屏蔽 Alt，F12 devtools 经 before-input-event 补回）；标题栏可选（跟随系统/开/关三态，跟随系统按 `system:detect-window-manager` 检测平铺 WM 隐藏、常规 DE 显示，fallback 显示）；v 菜单（最大化/最小化/退出）+ 最小化/最大化还原/关闭三按钮；标题规则（仪表盘「Hoshineko Nya~」/回收站/目录名/完整路径开关），经 document.title 实时同步 Electron 窗口标题

### 2. 文件浏览与导航

- 虚拟化文件列表（react-window + AutoSizer），网格/列表双视图，图标 16–128px 可调
- 语义分组（文件夹/媒体/文档/代码/压缩包/可执行文件/其他，可开关）
- 排序：名称/大小/日期，点击已选中键切换升降序
- 100+ 种 MIME 类型图标映射；图片经 `media://` 协议显示真实缩略图（懒加载、失败回退）
- 特殊条目样式：软链接（损坏标红）、块设备/挂载点徽标、隐藏文件开关
- 面包屑导航：家目录胶囊（多用户检测）、特殊挂载点胶囊、回收站胶囊、软链接斜体+展平、可编辑模式
- 地址栏（Omnibar）：路径导航与搜索二合一（`find -iname`，限 100 条）；**搜索结果右键「定位到所在文件夹」**——跳转父目录并滚动定位/选中目标条目（搜索结果与目录同名条目的竞态已处理）；**搜索高级过滤**（类型 文件/文件夹、最小/最大大小，maxSize 已处理 find -size 取整陷阱）
- 侧边栏：常用位置（Places）+ 设备区（外接磁盘树、挂载/卸载/弹出）
- 仪表盘：问候语、存储用量卡片、固定项（文件/目录，**支持拖拽排序**）、最近访问
- 状态栏：条目数、选中数、选择模式提示、悬停文件信息
- **全键盘导航体系**（键盘分区框架 `src/utils/focusZones.ts`）：
  - **Tab 分区循环**：Tab 在「功能栏 → places（侧边栏）→ 标签页 → 返回上级键 → 地址栏内 → 分类开关和排序方式 → 文件区」间循环停靠（Shift+Tab 反向；仪表盘为 功能栏-places-标签页-存储-固定项-最近访问 三子区；未注册分区自动跳过）；输入框/终端/对话框保持浏览器默认 Tab 行为；文件条目 `tabIndex=-1` 不进 Tab 序（修复 Tab 聚焦条目引发的键盘崩溃场景）
  - **分区内导航**：方向键移动（roving tabindex 或容器级）、Enter/Space 显式激活（注入键盘事件的 Enter 不合成原生按钮点击；分区级 stopPropagation + 变体切换丢焦点的 rAF 恢复）
  - **文件区键盘选择**：方向键 = 移动选择而非滚动——列表视图沿显示序（Up/Left 上一个、Down/Right 下一个，跳过分组头）；网格视图二维移动（左右同行、上下跨行且列位钳制到目标行长度，行首行尾不环绕）；无选中时 Down/Right 取首项、Up/Left 取末项；Home/End 首末项、PageUp/PageDown 翻页估算、Ctrl+方向键网格跳行首行尾/首末行、Space 切换选中、type-ahead 键入定位（1.5s 前缀累积）；Enter 打开游标条目、空选择回上级（虚拟目录除外）；**Tab 落到文件区 = 用文件区选择机制选中视口内第一个可见文件**（不直接聚焦条目，避免崩溃场景）
  - **Shift 范围选择**：锚点（lastSelectedPath）与游标（cursorPath）分离——Shift 连按方向键游标前进、锚点固定，范围随之扩展/收缩；列表 = 扁平序 anchor↔cursor 连续区间；网格 = (row, col) 对角线的矩形，分组头跳过（**跨分类连续**），列区间以**锚点行（基准行）**为准——游标在锚点行内时完全控制（行内收缩/扩展），游标在其他行时锚点行选区不收缩、游标只能在基准两侧扩展，短行按列区间钳制取全部（第一行 5 个、第二行 3 个时两行分别选 5/3）；鼠标 Shift+点击与键盘共用同一函数（修饰键点击不再污染双击检测）；主窗口与选择器窗口语义统一
  - **滚动控制**：越界目标经 `scrollToRow(align auto)` 最小滚动（完整可见不滚、否则只滚到恰好完整显示）；对话框焦点滚动校正（Chromium 居中滚动的修正，覆盖对话框 shadow scroller 与嵌套滚动容器）
  - **对话框键盘语义**：保持原生 Tab 序（如「打开方式」= 搜索框 → 程序列表第一项 → 取消 → 打开 → 循环，程序列表 role="listbox" + ↑/↓ 细选/Home/End/Enter）；无原生控件的行（设置主题颜色入口）补 role="button" + Tab 停靠 + Enter/Space 激活；标签页快捷键 Ctrl+Tab/Ctrl+Shift+Tab 切换、Ctrl+W 关闭、Ctrl+T 新建；布局计算与渲染完全同源（FileList 渲染期回传 `layoutRef`，`computeArrowTarget`/`computeShiftRange` 基于同一份 flattenItems 产物）；框选（覆盖模式）/取消选中/换目录后锚点与游标同步更新
- **文件预览面板**（设置 → 行为「文件预览」开关，默认关闭）：单选文件时文件区右侧「挤压」出预览区（与文件区一起随内置终端挤压，顶端与文件区平齐）；**面板常驻**——未选中条目时显示当前浏览目录的只读属性，**单选目录时显示该选中目录的属性**（回收站目录经 trashOriginalPath 显示原位置）；与右键属性对话框**共用 `PropertiesGrid` 共享网格**，预览侧 `canEditPermissions=false` 只读；`fs:get-dir-info` 轻量 IPC 只取 stat+属主（不含 du），大小单独走与对话框同一条 `getDirectorySize`（**全局单飞 + 10s 超时**——目录切换杀掉旧 du、超时/被杀显示「无法获取」，受设置「计算目录大小」开关控制，关闭显示「已禁用」），仅大小行「计算中」、其余字段秒回；trash:// 映射真实回收站目录）；分隔条拖动调整宽度（20%–60%，`settings.previewWidth` 持久化跨窗口同步）；**图片**（png/jpg/gif/webp/bmp/avif/svg/ico，`preview://` 原图）；**音频**（mp3/wav/ogg/flac/m4a/aac/opus，Chromium 原生解码）；**视频**（mp4/webm/ogg/quicktime/mkv，Range 206 分段支持 seek，编码不支持时提示失败）；**PDF**（pdfjs-dist 惰性加载独立 chunk，逐页 canvas 渲染**前 5 页**、超出时尾部显示「全文共 N 页」说明；页面宽度随预览区宽度自适应缩放，ResizeObserver 测宽 + dpr ≤ 2；**重渲染/卸载时 cancel 进行中的 render 任务**——修复画布重置后旧任务继续绘制导致的第一页黑屏/上下翻转）；**归档内容列表**（zip/jar/apk 走 `unzip -Z1`、tar 系走 `tar -tf`、7z 走 bsdtar/7z，上限 5000 条截断提示）；**Markdown 渲染**（marked + DOMPurify 消毒，**本地相对图片按文档所在目录解析为 `preview://` 绝对路径**）；**文本/代码**（512 KiB 上限，超限 TOO_LARGE 提示）；**内容变化自动刷新**——外部编辑保存后（fs:dir-changed → 重列目录带来新 mtime）文本/Markdown/PDF/归档自动重载，媒体与 PDF URL 带 `?v=mtime` 缓存戳强制重新加载；多选显示「多个文件无法预览」占位；不可预览文件/取消选择/目录/仪表盘视图隐藏；回收站（path 为 Trash/files 真实文件）与搜索结果均可预览

### 3. 文件操作

- 新建文件/文件夹（带冲突安全名）、重命名（对话框 + 行内）、**批量重命名**（查找替换/前缀/后缀/序号四种模式，实时预览 + 冲突检测；**多选右键菜单只显示「批量重命名...」（去掉单项重命名）；对话框文件顺序跟随当前排序/分组模式的视觉顺序**——列表从上到下、网格行主序）
- 复制/剪切/粘贴：跨窗口共享剪贴板（主进程持有 + 持久化到 `clipboard.json`，重启后可粘贴）
- 删除进回收站；永久删除走批量任务管线（确认框含条目数与总大小）
- 就地解压（zip/tar/gz/xz，`unzip`/`tar`）
- **压缩为 zip / tar.gz**（右键「压缩...」→ CompressDialog：归档名 + 格式选择，`zip -r`/`tar -czf` argv 安全；已存在归档返回 EXISTS 绝不覆盖；zip 缺失返回 NO_TOOL 结构化提示）
- 系统默认打开、打开方式（`.desktop` 推荐应用 + 全部应用 + 搜索过滤，`gio launch` 保环境变量）
- 批量任务系统（copy/move/trash/delete）：进度 toast、可取消、部分失败提示
- 错误码本地化（EEXIST/ENOENT/EACCES/ENOSPC/EROFS/EISDIR/ENOTDIR/EXDEV/EBUSY 等）
- 跨设备移动（EXDEV）自动回退复制+删除；目标父目录不存在自动创建
- 外部文件拖入导入

### 4. 回收站（freedesktop Trash 规范）

- `trash://` 虚拟目录：解析 `.trashinfo`（percent 解码、删除时间），按时间倒序
- 还原（按原始目录分组处理冲突）、永久删除、清空回收站
- 监听真实 Trash 目录，外部改动自动刷新；空状态提示
- 拖入 = 移入回收站；拖出 = 还原（带确认）

### 5. 拖拽系统

- 原生 OS 拖拽（`webContents.startDrag`），外部应用（LocalSend 等）可收到真实文件
- 三种来源：窗口内部、跨窗口（主进程 claim 仲裁）、外部应用
- 落点：文件条目/列表背景/面包屑胶囊/标签页/**地址栏背景（= 复制/移动到当前目录）**；Shift 强制复制
- 冲突对话框：跳过/自动重命名/手动重命名（逐项编辑+实时校验）；「取消」选项；串行化弹窗
- Wayland 兜底：光标静止合成 drop、幻影 drop-back 抑制、单次消费仲裁

### 6. 标签页

- 多标签（新建/关闭/切换），支持虚拟路径（`app://dashboard`、`trash://`）
- 每标签独立路径/排序/分组状态；非活动标签隐藏
- 拖文件到标签页 = 移动/复制到该标签目录
- 切换回标签自动刷新（watcher 摘除期间变更不残留）

### 7. 终端

- 内置终端（xterm.js + node-pty）：任意目录打开、自适应尺寸、多窗口会话隔离、窗口关闭自动 kill
- 在系统默认终端中打开目录 / 运行可执行文件（右键菜单，含可执行位判断）
- **自定义终端**：读取 `~/.config/HoshinekoFM/terminal.conf`（`command = <终端>` 或裸命令）覆盖默认终端，优先级高于 $TERMINAL/xdg-terminal-exec 等全部检测链；参数风格按 basename 查规格表，未知终端回退通用 `-e`
- 默认终端检测链 7 级：`$TERMINAL` → `xdg-terminal-exec` → `gsettings` → `exo-open` → KDE 配置 → 常见终端扫描 → `x-terminal-emulator`；含各终端参数风格表；ghostty 单实例 cwd 问题已修复

### 8. 设备管理

- 完整设备树（`lsblk`）、挂载/卸载/弹出（`udisksctl`）
- UDISKS2 D-Bus 热插拔监听（`dbus-next`），不可用时降级轮询；事件广播所有窗口
- 弹出失败结构化错误码（`PARTITIONS_MOUNTED`）、未格式化设备提示
- `/dev` 目录块设备类型图标（isMountable/可挂载标记）

### 9. 对话框与交互

- 属性对话框：位置/大小（目录 `du` 异步计算）/修改时间/权限位（`drwxr-xr-x`）/属主（用户名:组名，回退 UID/GID）/类型；**权限编辑（chmod）**——3 位八进制输入 + 实时校验，成功后更新显示并刷新目录
- 冲突、重命名、新建名称、拖拽动作（移动/复制/取消）、打开方式、M3 确认对话框
- 右键菜单：按条目类型动态生成（文件/目录/设备/回收站/背景），批量操作作用于完整选中集，触屏长按适配
- 选择：Ctrl/Shift 多选、Ctrl+A、橡皮筋框选（replace/union/intersection/difference 四模式+边缘自动滚动）
- 快捷键：Ctrl+A / F5 / Delete / Shift+Delete / Ctrl+C / Ctrl+X / Ctrl+V

### 12. 后端基础设施

- 目录列表六阶段流水线：16 并发分类 → 批量 MIME（魔数 4 级策略 + 30s TTL 缓存）→ 挂载信息富化 → passwd/group 富化
- 目录监听（inotify）按窗口注册、全局去重、300ms 防抖
- 任务系统（job:start/cancel/progress/complete，AbortController 取消）
- MIME 检测：魔数 → 扩展名表（约 300 个）→ 文件名表 → `file` 命令兜底；容器/冲突仲裁表
- 缩略图生成（ImageMagick 优先 + nativeImage 回退，磁盘缓存）：**全局队列化**——未命中缓存的生成走并发上限（默认 6，`HOSHINEKO_THUMB_CONCURRENCY` 可覆盖）+ in-flight 去重 + **世代优先 + 世代内 FIFO**（渲染侧排序/目录变化时 URL 携带 ?v=世代，新世代整体压过旧视口陈旧任务，同世代内到达序 = DOM 序 = 上→下，首屏顶部先生成）+ 队列满淘汰最旧（回退原文件服务），冷缓存大图片目录首开不再 fork 风暴/OOM；**提速**——JPEG 源 `-define jpeg:size` 按目标分辨率解码（DCT 降采样，**必须放在输入文件之前**——实测 24MP：40ms/20MB vs 160ms/297MB，4 倍速度、15 倍内存）+ 输出 q80 .jpg（缓存体积约 10 倍小），非 JPEG 源 PNG 编码级别降 1（透明无黑底）；**尺寸随图标大小动态调整**——`media://` 携带 `&s=<尺寸>`（图标 × 2 HiDPI 预留，分桶 [64, 96, 128, 192, 256]，默认 64px → 128px 替代固定 256px），各尺寸独立缓存，桶化避免滑条每格重生成；**崩溃防护**——`-limit memory/map 128MiB` 硬内存护栏（超限巨图改走磁盘缓存）、GIF 只解第一帧、convert 30s 超时、nativeImage 兜底限 25MB（宁慢不崩）
- 拖拽图标渲染缓存、`media://` 协议（缩略图）、`preview://` 协议（预览面板原图/视频/音频/PDF，`preview://localhost` 形态 + standard/corsEnabled 注册，Range 206 流式分段）、挂载表 30s 缓存
- 权限失败回退到最近可访问父目录

## 四、剩余项目工作逻辑（计划）

> 本节为剩余未实现项目的**技术实施逻辑**说明，
> 供后续开发按此推进，避免重新调研。
> （收藏夹/书签、格式化、e2e 固化三项已按用户决策移除：前两项有意
> 不做，e2e 已实施。）

### 1. 自动更新

- 依赖 `electron-updater`；主进程新增 `electron/updater.ts`：
  `autoUpdater.checkForUpdatesAndNotify()`（app ready 后 10s 延迟触发，
  避免影响启动），`update-downloaded` 时提示重启（复用 ConfirmDialog
  样式的主进程 dialog）。
- AppImage 部署需 `publish` 配置（GitHub Releases / generic URL）与
  `electron-builder` 的 `latest-linux.yml` 一致；`latest-linux.yml`
  已存在于构建产物说明发布链路曾配置过，补上依赖与 handler 即可。
- 无网络/失败时静默（仅 console.warn），不打扰用户。

### 2. 跨平台支持（长期工程）

- 分层替换：`electron/` 下按平台拆实现（`fsLinux.ts`/`fsWin.ts`），
  共享接口（列目录/挂载/设备/MIME/终端检测），`electron/main.ts`
  按 `process.platform` 注册。
- 优先 Windows 支持（用户基数大）：替换 `lsblk`→`wmic/powershell
  Get-Disk`、`du`→walk、`find`→递归遍历、inotify→`fs.watch`、
  回收站→`shell.trashItem` 已跨平台；macOS 用 `diskutil`/`df`。
- 每完成一个平台再启用对应 electron-builder target；PTY 已有 win32
  分支（`electron/pty.ts`）。
