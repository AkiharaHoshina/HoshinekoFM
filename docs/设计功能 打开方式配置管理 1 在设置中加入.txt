设计功能：打开方式配置管理
{
  1.在设置中加入“打开方式配置管理”项，右侧有按钮“进入”
     2.点击按钮时进入二级对话框，长宽和设置一样，并有背景遮罩{
     	3.对话框标题为“打开方式配置管理”，页脚有按钮“完成”（按下式关闭二级菜单返回设置）
     	4.对话框内容为可滚动区域，内部以列表形式列出所有的系统默认打开方式和用户打开方式配置{
     	    5.复用文件分类给配置分类，标题为“用户配置”、“系统配置”，顺序为用户先系统后
     	    	6.用户配置每一项显示基本信息：标题为文件类型，副标题为"打开方式：路径"，如果鼠标放在项上，则在右侧显示编辑图标，点击项目时启用编辑界面{
     	    	    7.编辑界面定义：标题=编辑 内容是一个输入框，可供用户输入路径（亦可以处理~路径并区分带～文件，输入框下方有按钮清除配置 快速导入 取消 确定。清除配置会（草稿）清除输入框里内容。快速导入是复用打开方式对话框，但做略微修改，打开按钮改为确定，点击确定后把选定的应用信息写入（草稿）对话框。取消是丢弃更改关闭。确定是保存更改关闭。（如果输入框为空，则删除配置，回归系统默认））
     	    	}
     	    	8.系统配置的每一项显示基本信息：标题为文件类型，副标题为打开方式应用名（如有完整路径，则显示完整路径），如果鼠标放在项上，右侧显示复制图标，点击项目时把配置按照文件管理器的格式写入用户配置目录。如果用户配置有针对同一文件类型的配置覆盖了此系统设置项，则右侧显示X按钮，并无效化鼠标点击写入。
     	}
     	9.对话框内容底部常住不可滚动提示：系统配置为只读，需要复制配置到用户配置以修改。同一种文件，优先使用用户配置声明的打开方式。
     	
     }
}
