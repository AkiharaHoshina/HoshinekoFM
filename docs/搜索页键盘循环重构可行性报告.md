# 搜索页键盘循环重构可行性报告（review 23）

> **状态：决策点已全部定案并实施**（2026-10-01）。范围：优先级数值提示、文件搜索态 Tab 循环顺序重构（下拉/条件输入/词条独立成站 + 回切回车站聚焦输入框）、快捷添加对话框内循环、对象搜索回切/回车站聚焦输入框。渲染层改动，无后端/IPC 变更。
> 调研基准：v0.11.49-dev（review 22 `7a77f29` 之后）。
> **决策点定案**：① 「(更高)/(更低)」基准 = 相对 nice 0；② 批量滑条数值 span 同款一起改；③ 对象搜索统一新全局序列；④ 回切/回车按钮 = 输入框承接（Enter 提交、Esc 退出，移除 ←/→ 微调）；⑤ 快捷添加对话框键盘 ↑/↓ 单选移动、Shift+方向键 = 从选中项到终点范围多选（文件区列表模式同款）、鼠标单选/多选切换；⑥ 回收站名称过滤同新序列。

## 1. 需求解读（三项）

1. **优先级滑条右侧数字显示真实值 + 相对提示**：数字显示 nice（真实值，review 22 只改了气泡）；nice ≠ 0 时附加「(更高)」/「(更低)」。
2. **文件搜索态 Tab 循环重构**（完整序列）：
   左侧栏 → Places → 标签页栏 → 返回上级按钮 → 回切按钮 → 回车按钮 → 右上角按钮群 → 文件类型下拉（Enter 开启、内部方向键选择）→ 筛选模式下拉（同上）→ [按模式条件输入区] → 最近搜索项（含删除按钮）→ 搜索结果（无选择选首个、有选择保持并给焦点）→ 循环。
   - 按大小：最小大小输入框 → 最大大小输入框 → 确认按钮；
   - 按格式：扩展名输入框 → 添加按钮 → 快捷添加按钮 → 确认按钮。
   - 快捷添加对话框打开时进入再一级内循环：搜索框 → 已注册格式单项（无选择选首个、有则保持；Tab 选中给单项白框、上下键移动后白框消失）→ 显示不完整注册按钮 → 取消按钮 → 确认按钮 → 循环。
   - **回切/回车按钮站选中时焦点应在搜索框上**（可立即输入关键词）。
3. **对象搜索**：回切/回车按钮站同样聚焦搜索框。

## 2. 现状盘点（file:line 证据）

- 优先级数值 span：`{-r.nice}`（ObjectPanel 实例页）与 `{-batchNiceValue}`（批量）——显示优先级（取反值）。
- 第二循环：`SEARCH_ZONE_ORDER = [search-back, search-submit, search-filters, search-results]`（focusZones.ts:80-84）——**不含** nav/sidebar/tabbar/topbar-up/topbar-sort（review 19 定案「完全替换第一循环」）。
- 回切/回车站聚焦按钮本体：Omnibar.tsx:452-457（`.omnibar-back-address`/`.omnibar-start-search`）。
- 搜索筛选条单站：SearchFilterBar 整个 band 挂 `data-kb-zone="search-filters"`（:337）+ `handleFilterNavKey` ←/→ 微调（:330）；类型/模式下拉、条件输入区（大小/格式）、确认按钮都在同一站内。
- 最近搜索词条行（文件侧）非站：review 21 加了 ←/→ roving 但无 Tab 停靠。
- 快捷添加对话框（QuickAddDialog，SearchFilterBar.tsx:568-663）：搜索框 + md-list-item 列表 + 显示不完整注册/取消/确认——无任何键盘循环处理。
- 对象侧 ObjectSearchFilterBar 注册 `search-filters` 站（复用同名站 id）。
- App 全局 Tab 拦截：INPUT/TEXTAREA/md 文本域**早退**（浏览器原生 Tab）——输入框站进站后 Tab 走 DOM 序；对话框打开时全局拦截早退。

## 3. 设计

### 3.1 优先级数值 + 提示（问题 1）

- 实例页/批量数值 span 改显示 `{nice}`（真实值）+ 相对默认优先级（nice 0）提示：nice < 0 → ` (更高)`、nice > 0 → ` (更低)`；nice = 0 无提示。
- 新 i18n 键 `objects.nice_higher` / `objects.nice_lower` × 12。
- 滑条位置/方向/气泡（valueLabel）不变。

### 3.2 文件搜索态循环重构（问题 2）

- **SEARCH_ZONE_ORDER 扩为单一全局序列**（文件/对象搜索共用，未注册自动跳过）：
  `nav → sidebar → tabbar → topbar-up → search-back → search-submit → topbar-sort → search-type → search-mode → search-size-min → search-size-max → search-ext-input → search-format-add → search-format-quickadd → search-confirm → search-filters（对象侧）→ search-recent → search-results`。
- SearchFilterBar 拆站注册（keyboardCycle 门控，按 filterMode 条件注册）：
  - 恒注册：search-type（类型下拉）、search-mode（模式下拉）；
  - size 模式：search-size-min / search-size-max / search-confirm；
  - format 模式：search-ext-input / search-format-add / search-format-quickadd / search-confirm；
  - 各控件自身挂 data-kb-zone（focusin 跟踪）；输入框站进站后 Tab 走原生 DOM 序（min → max → confirm / ext → add → quickadd → confirm 恰好与期望一致——App 对输入框早退）。
- **search-recent 新站**：文件侧词条行挂 data-kb-zone 注册（focus = 当前/首词条；←/→ roving 已有）。对象侧浏览态 object-recent 不变；对象搜索态不渲染词条行 → 跳过。
- **回切/回车站聚焦搜索框**：Omnibar 两站 focus 改 `.omnibar-input`（对象/文件同款——问题 3 一并解决）；输入框 Enter = 提交（既有）、Esc = 退出搜索（回切语义既有）；按钮本体仍鼠标可达。
- 回收站名称过滤（nameFilterOnly）：无类型/模式/条件站注册 → 循环 = nav → sidebar → tabbar → up → back → submit → sort → recent → results。

### 3.3 快捷添加对话框内循环（问题 2 追加）

- QuickAddDialog 打开期间窗口级**捕获** Tab/Shift+Tab 拦截（App 对打开对话框已早退，不冲突）：搜索框 → 单项列表站 → 显示不完整注册 → 取消 → 确认 → 循环。
- 单项列表站（与 review 20 白框同款语义）：Tab 进站无选中先选首个、有则保持；进站焦点落**选中项**（白框只框选中单项）；↑/↓ 移动单选（radio 语义——点击仍为多选切换，见决策点 5）+ 焦点回列表容器（白框消失）。
- md-list-item 选中项白框：:focus-visible 焦点环 + 列表容器 outline:none（review 20 同款）。

## 5. 决策点（已全部定案）

1. **「(更高)/(更低)」基准**——**定案**：相对 nice 0（nice < 0 更高、> 0 更低、= 0 无提示）。
2. **批量滑条数值 span**——**定案**：与实例页同款（nice + 提示）。
3. **对象搜索循环**——**定案**：统一新全局序列（对象搜索也获得 chrome 站，未注册站自动跳过）。
4. **回切/回车按钮激活**——**定案**：输入框承接（Enter = 提交、Esc = 退出搜索；按钮仅鼠标可达；移除 ←/→ 微调）。
5. **快捷添加对话框选择语义**——**定案**：键盘 ↑/↓ 单选移动、Shift+方向键 = 从选中项到终点范围多选（文件区列表模式同款）、鼠标点击 = 单选/多选切换。
6. **回收站名称过滤循环**——**定案**：同新序列（跳过未注册站）。
